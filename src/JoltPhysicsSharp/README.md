# JoltPhysicsUnity

Development UPM package: `com.ciart.joltphysics`, version `0.1.0-preview.1`.

The complete Unity assembly and native interop are still being ported. Adding this package does not yet provide a working physics runtime.

See the [repository README](https://github.com/ciart/JoltPhysicsUnity#readme) for Git installation instructions and current validation status, and the [upstream change log](https://github.com/ciart/JoltPhysicsUnity/blob/main/Unity~/Documentation/UpstreamChanges.md) for implementation records.

The Unity adaptation is written and modified using GPT (Codex). The original JoltPhysicsSharp bindings are by Amer Koleci and contributors. Their MIT license and copyright notices are preserved in [LICENSE](LICENSE).
